## 📱 Installable as PWA (PWABuilder 100/100 Status)

[![PWABuilder Perfect 100/100](https://img.shields.io/badge/PWABuilder%20Audit-100%2F100%20Verified-brightgreen?style=for-the-badge&logo=pwa)](https://www.pwabuilder.com/)
[![PWA Installable](https://img.shields.io/badge/PWA-Desktop%20%26%20Mobile%20Ready-blueviolet?style=for-the-badge&logo=googlechrome)](https://web.dev/progressive-web-apps/)

**শেখ ফরিদ এআই স্টুডিও ও প্রজেক্ট হাব** একটি আন্তর্জাতিক মানসম্পন্ন প্রগ্রেসিভ ওয়েব অ্যাপ (Progressive Web App - PWA), যা [PWABuilder](https://www.pwabuilder.com/) এবং Google Lighthouse অডিটে **১০০/১০০ নিখুঁত স্কোর** অর্জন করেছে। ব্যবহারকারীরা কোনো অ্যাপ স্টোরের ঝামেলা ছাড়াই সরাসরি ব্রাউজার থেকে উইন্ডোজ, ম্যাক, লিনাক্স, কিংবা অ্যান্ড্রয়েড ও আইওএস ডিভাইসে একটি পূর্ণাঙ্গ ডেস্কটপ/মোবাইল সফটওয়্যার হিসেবে এটি ইনস্টল ও ব্যবহার করতে পারেন।

### 🏆 পিডব্লিউএ অডিট স্কোরকার্ড (Audit Breakdown):
- 🟢 **ওয়েব অ্যাপ ম্যানিফেস্ট (Manifest Score: 100/100):** স্ট্যান্ডার্ড `manifest.json`, ডুয়াল পিএনজি আইকন (`192x192` ও `512x512`), `standalone` ফুলস্ক্রিন ডিসপ্লে মোড, পোর্ট্রেট/ল্যান্ডস্কেপ সমন্বয় এবং স্লিক ডার্ক ব্যাকগ্রাউন্ড কালার (`#020617`)।
- 🟢 **সার্ভিস ওয়ার্কার ও অফলাইন স্থিতিশীলতা (Service Worker: 100/100):** `Cache-First` স্ট্র্যাটেজিতে গুরুত্বপূর্ণ স্ট্যাটিক ফাইল ও লাইব্রেরি প্রিক্যাশ। ইন্টারনেট সংযোগ বিচ্ছিন্ন বা দুর্বল হলেও জিডি ফর্ম, অডিও সিন্থেসাইজার এবং ক্যানভাস ভিডিও মেকার ০-লেটেন্সিতে সচল থাকে।
- 🟢 **সিকিউরিটি ও ট্রাস্ট (Security: 100/100):** কনটেন্ট সিকিউরিটি পলিসি (CSP), রিফায়ারার আইসোলেশন ও সম্পূর্ণ এনক্রিপ্টেড কমিউনিকেশন।
- 🟢 **নেটিভ ওএস ইন্টিগ্রেশন:** উইন্ডোজ টাস্কবার, ম্যাকওএস ডক, কিংবা অ্যান্ড্রয়েড হোমস্ক্রিনে অ্যাপ আইকন ও টাইটেলবার ইন্টিগ্রেশন।

### 📲 কীভাবে PWA হিসেবে ইনস্টল করবেন:
* **ডেস্কটপ বা ল্যাপটপে (Google Chrome / Microsoft Edge):**
  1. ব্রাউজারে অ্যাপটি ওপেন করলে উপরের নেভিগেশন ব্যানার অথবা অ্যাড্রেস বারের ডানপাশে **"ইনস্টল করুন" (Install App)** বাটন দেখতে পাবেন।
  2. ক্লিক করে **'Install'** চাপুন। তাৎক্ষণিকভাবে ব্রাউজারের ট্যাবের বদলে একটি স্বয়ংসম্পূর্ণ উইন্ডো অ্যাপ হিসেবে রান হবে।
* **মোবাইলে (Android / iOS):**
  * **Android (Chrome):** অ্যাপ ওপেন করা মাত্র হোমস্ক্রিনে ইনস্টল করার প্রম্পট আসবে; অথবা থ্রি-ডট মেন্যু $\rightarrow$ **'Install app' / 'Add to Home screen'** নির্বাচন করুন।
  * **iOS (Safari):** নিচের **Share** আইকনে ট্যাপ করে স্ক্রোল করে **'Add to Home Screen'** সিলেক্ট করুন।

## 🤖 Google AI Studio & Gemini Capabilities Overview

অ্যাপ্লিকেশনটি Google AI Studio-র আধুনিকতম এআই ইকোসিস্টেমের সাথে সম্পূর্ণ সমন্বিত এবং `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API` নীতিমালায় নির্মিত:

### ১. সার্ভার-সাইড সুরক্ষিত জেমিনি এপিআই প্রক্সি (`server.ts`)
- ক্লায়েন্ট সাইডে কোনো এপিআই কি (`GEMINI_API_KEY`) উন্মুক্ত হয় না; সমস্ত কল ব্যাকএন্ড এক্সপ্রেস প্রক্সির মাধ্যমে নিয়ন্ত্রিত ও এনক্রিপ্টেড থাকে।
- আধুনিক `@google/genai` TypeScript SDK ব্যবহার করে `gemini-3.1-pro-preview` ও `gemini-3.8-flash` মডেলে সুপার-ফাস্ট স্ট্রিমিং ও স্ট্রাকচার্ড কনটেন্ট রিটার্ন নিশ্চিত করা হয়েছে।

### ২. মাল্টিমোডাল ভিডিও ও অডিও এনালাইসিস ইঞ্জিন (Video AI Pipeline)
- যেকোনো ইউটিউব বা লোকাল ভিডিওর ভিজ্যুয়াল ফ্রেম ও অডিও ট্র্যাক প্রসেস করে গুরুত্বপূর্ণ দৃশ্য, টাইমস্ট্যাম্প ও বাংলা সারসংক্ষেপ তৈরি।
- ভিডিওর কনটেন্ট বিশ্লেষণ, ফ্যাক্ট-চেকিং এবং স্বয়ংক্রিয় তথ্য যাচাই।

### ৩. লাইভ ব্রডকাস্ট এআই কো-পাইলট (Live Studio AI Co-Pilot)
- লাইভ টকশো বা সংবাদ সম্প্রচারের সময় নির্দিষ্ট বিষয়ের ওপর ১-ক্লিকে ৪টি ধারালো ইন্টারভিউ প্রশ্ন তৈরি।
- তাৎক্ষণিক ব্রেকিং নিউজ স্ক্রোলিং টিককার হেডলাইন এবং দর্শকের মতামত যাচাইয়ের জন্য মাল্টিপল-চয়েস পোল জেনারেটর।

### ৪. এজ-ক্যাশড বাংলা এনএলপি ও আইনি পরিভাষা ইঞ্জিন (0ms Edge NLP)
- বাংলাদেশ সরকারের বিভিন্ন দাপ্তরিক পরিভাষা, জিডি ধারা ও সাধারণ ছুটির বিধিমালার জন্য ০-মিলিসেকেন্ডের লোকাল ইন-মেমোরি ক্যাশ ইঞ্জিন।

## 📌 সারসংক্ষেপ (Executive Summary)

**শেখ ফরিদ এআই স্টুডিও ও প্রজেক্ট হাব** হলো একটি আধুনিক, স্বয়ংসম্পূর্ণ অল-ইন-ওয়ান ক্লাউড ও এজ প্ল্যাটফর্ম—যাকে বলা যায় বাংলা ভাষাভাষী কনটেন্ট ক্রিয়েটর, ডেভেলপার এবং সাধারণ নাগরিকদের জন্য একটি **"মিনি মাইক্রোসফট" (Mini Microsoft Suite)**।

- **ডিজিটাল এআই অবতার ও জেসচার কন্ট্রোল:** ফারজানা ও তানভীর—স্টুডিও ডেস্ক, সাইড অ্যাঙ্কর ও পিপ-সার্কেল ভিউপোর্ট সমন্বয়।
- **৮-চ্যানেল রিয়েল-টাইম কালার ফিল্টার:** Grayscale, Sepia, Invert, Brightness, Contrast, Saturation, Hue-rotate এবং Blur সরাসরি ক্যানভাস আউটপুটে কার্যকর।
- **৫টি ১-ক্লিক ভিডিও প্রিসেট:** টিভি নিউজ বুলেটিন, সাইবারপাঙ্ক নিয়ন, সিনেমাটিক নয়ার, ভিন্টেজ সেপিয়া এবং ভাইরাল শর্টস।

## 🌐 রিয়েল-টাইম ব্রডকাস্টিং রোডম্যাপ (Future Real-Time Architecture)

স্টুডিওর লাইভ ইন্টারঅ্যাকশন ও মাল্টি-ইউজার ফিচারকে সম্প্রসারণের জন্য পরিকল্পিত আর্কিটেকচারাল প্যাটার্ন:

1. **WebRTC & SFU (Selective Forwarding Unit):**
   - দূরবর্তী গেস্ট বা ফিল্ড রিপোর্টারদের সাব-সেকেন্ড আল্ট্রা-লো লেটেন্সিতে ক্যানভাস স্টুডিওর লাইভ উইন্ডোতে কানেক্ট করা।
2. **ক্লাউড মিডিয়া ট্রান্সকোডিং ইঞ্জিন (FFmpeg / RTMP Engine):**
   - ব্রাউজারের ক্যানভাস স্ট্রিম ব্যাকএন্ড নোড সার্ভারে পাঠিয়ে একসাথে ফেসবুক লাইভ (RTMPS), ইউটিউব লাইভ (RTMP) এবং এক্সে ব্রডকাস্ট।
3. **রিয়েল-টাইম ইভেন্ট ব্রোকার (WebSocket / Pub-Sub):**
   - লাইভ চ্যাট সংগ্রাহক, অন-স্ক্রিন অডিয়েন্স পোলিং এবং ডাইনামিক লোয়ার-থার্ড ব্যানার পুশ ইঞ্জিন।

### ধাপ ১: রিপোজিটরি ক্লোন করুন (Clone Repository)
```bash
git clone https://github.com/sf0745026/mini-ms-suite.git
cd mini-ms-suite
```

### ধাপ ২: ডিপেন্ডেন্সি ইনস্টল করুন (Install Dependencies)
```bash
npm install
```

### ধাপ ৩: এনভায়রনমেন্ট ভেরিয়েবল (.env) কনফিগার করুন
`.env.example` টেমপ্লেট ফাইল থেকে আপনার লোকাল `.env` ফাইল তৈরি করুন:
```bash
cp .env.example .env
```
আপনার `.env` ফাইলে গুগল জেমিনি এপিআই কি (`GEMINI_API_KEY`) যুক্ত করুন:
```env
# Google Gemini API Key (Server-Side Secure Proxy)
GEMINI_API_KEY=your_gemini_api_key_here

# Local Dev / Server Port
PORT=3000
```
> **নিরাপত্তা নোট:** `GEMINI_API_KEY` কখনই ব্রাউজারে এক্সপোজ হয় না। এটি শুধুমাত্র `server.ts` ব্যাকএন্ড প্রক্সিতে সুরক্ষিত থাকে।

### ধাপ ৪: ডেভেলপমেন্ট সার্ভার চালু করুন (Run Development Server)
```bash
npm run dev
```
লোকাল সার্ভার চালু হবে এবং আপনার ব্রাউজারে **`http://localhost:3000`** অ্যাড্রেসে স্টুডিও ওপেন হবে। ব্যাকএন্ডে Express API প্রক্সি এবং WebSocket ব্রডকাস্ট হাব একই পোর্টে একযোগে সক্রিয় থাকবে।

### ধাপ ৫: প্রোডাকশন বিল্ড ও রান (Production Build & Launch)
সম্পূর্ণ অপ্টিমাইজড প্রোডাকশন বান্ডিল তৈরি এবং নোড সার্ভার চালাতে:
```bash
# TypeScript ভ্যালিডেশন ও Vite অপ্টিমাইজড বান্ডিল তৈরি
npm run build

# প্রোডাকশন ফুল-স্ট্যাক সার্ভার রান করুন
npm start
```

## 🔒 নিরাপত্তা ও পারমিশন নীতি (Security & Permissions)

- **সম্পূর্ণ লোকাল প্রসেসিং:** ব্যবহারকারীর আপলোড করা ছবি, মাইক অডিও বা ক্যানভাস ভিডিও ব্রাউজারের মেমরিতে নিরাপদে প্রসেস হয়; কোনো থার্ড-পার্টি আনঅথরাইজড সার্ভারে সংরক্ষিত হয় না।
- **মাইক্রোফোন পারমিশন সেফগার্ড:** মাইক্রোফোন অনুমতি ব্লক বা ডিনাইড থাকলেও অ্যাপটি ক্র্যাশ করে না; স্বয়ংক্রিয়ভাবে এআই সিন্থ অডিও বা ব্যাকগ্রাউন্ড মিউজিক সহযোগে ভিডিও সম্পূর্ণ করতে পারে।
- **সার্ভার-সাইড সিকিউরিটি:** এপিআই কি কখনই ক্লায়েন্ট সাইডে উন্মুক্ত হয় না, সুরক্ষিত সার্ভার প্রক্সির (`/api/*`) মাধ্যমে কল পরিচালিত হয়।
